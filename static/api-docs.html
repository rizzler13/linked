API Reference

link-ed is an AI-powered website intelligence API. Submit any public URL and receive structured analysis across five dimensions: brand profile, competitor intelligence, targeted search queries, SEO improvements, and audience segments.

The pipeline fetches the URL, extracts structured content across seven layers (JSON-LD → OpenGraph → meta tags → navigation → headings → body → footer), then runs a two-stage LLM analysis using Gemini with Groq as a fallback.

ℹ Analysis typically takes 15–25 seconds per URL. Results are cached for 10 minutes — repeated requests to the same URL return instantly.

Base URL

http://localhost:4000  
https://linked-6oi2.onrender.com/

Authentication

The API does not require client authentication. API keys for Gemini and Groq are configured server-side via environment variables and are never exposed to clients.

VariableDescriptionRequired
GEMINI_API_KEYGoogle Gemini API key — primary LLM providerRequired
GROQ_API_KEYGroq API key — fallback LLM providerOptional

Set these in a .env file at the project root. See .env.example for the template.

Rate Limits & Caching

LimitValueScope
Request rate5 requests per minutePer IP address
Result cache TTL10 minutesPer URL
Cache size100 URLsServer-wide (LRU)
Body size2 MB maxPer fetched page

When the rate limit is exceeded, the API returns 429 Too Many Requests. When a URL is cached, the response includes the same request_id and latency_ms as the original analysis.

Analyze a website

POST /link-analysis

Fetches the website at the given URL, extracts content, and returns structured business analysis across five sections.

Request

Headers

Content-Type: application/json

Body

FieldTypeRequiredDescription
url string Required Fully qualified URL to analyze. Must start with http:// or https://. Private/internal addresses are blocked (SSRF protection).

Example request

curl -X POST http://localhost:4000/link-analysis \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://stripe.com"
  }'

Response

All successful responses have HTTP 200 and return JSON with the following top-level shape:

{
  "success": true,
  "website": "https://stripe.com",
  "meta": { ... },
  "brand": { ... },
  "analysis": {
    "competitor_analysis": { ... },
    "target_search_queries": [ ... ],
    "seo_improvements": { ... },
    "top_services": [ ... ],
    "target_audience": { ... }
  }
}

target_audiencestringWho would use this query

Meta Envelope

Operational metadata included in every response.

FieldTypeDescription

Error Codes

Error responses have the shape {"success": false, "error": {"code": "...", "message": "..."}}.

HTTPCodeCause
400SSRF_BLOCKEDURL resolves to a private/loopback/internal address
413CONTENT_TOO_LARGEResponse body exceeds 2 MB
415NOT_HTMLURL returned a non-HTML content type (PDF, JSON, etc.)
422—Request body validation failed (missing or invalid url)
429—Rate limit exceeded (5 req/min per IP)
502SITE_UNREACHABLETarget website refused connection or returned 4xx/5xx
503LLM_UNAVAILABLEBoth Gemini and Groq failed or are unavailable
504FETCH_TIMEOUTTarget website did not respond within 25 seconds

Full Example

Request

POST /link-analysis HTTP/1.1
Host: localhost:4000
Content-Type: application/json

{
  "url": "https://stripe.com"
}

Response (abbreviated)

{
  "success": true,
  "website": "https://stripe.com",
  "meta": {
    "request_id": "a1b2c3d4-...",
    "provider": "gemini",
    "model": "gemini-3-flash-preview",
    "latency_ms": 21340,
    "content_quality": "partial",
    "pages_fetched": 1
  },
  "brand": {
    "name": "Stripe",
    "category": "Financial Services & Fintech",
    "summary": "Global payments infrastructure for internet businesses.",
    "site_type": "saas"
  },
  "analysis": {
    "competitor_analysis": {
      "competitors": [
        {
          "name": "Braintree",
          "domain": "braintreepayments.com",
          "domain_verified": true,
          "source": "ai_suggested"
        }
      ]
    },
    "top_services": [
      {
        "service_name": "Payments",
        "source": "extracted",
        "url": "https://stripe.com/payments"
      }
    ]
  }
}
↗ The url field on services is populated when the LLM finds a direct link to that service page in the crawled HTML — for example, a navigation link to https://stripe.com/payments.
